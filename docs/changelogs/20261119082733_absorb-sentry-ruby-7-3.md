# Absorb sentry-ruby / sentry-rails 7.3

## Participants

- Andrei Makarov

## Decisions

- Keep publishing this gem; no deprecation in this change.
- On sentry-rails 7.2: keep enhancing `SentryReporter.sentry_context` when that method exists.
- On sentry-rails 7.3+: skip the removed `sentry_context` alias; prepend `Sentry::GoodJob::RailsActiveJobExtension` onto `Sentry::Rails::ActiveJobExtension` so Good Job context attaches for any adapter when the job exposes those fields.
- Pin appraisal cells to `sentry-ruby` / `sentry-rails` `~> 7.3.0`. Gemspec remains `>= 7.0, < 8.0`.

## Effects

- Setup no longer raises when `SentryReporter` has no `sentry_context` (7.3 job-extension path).
- Good Job `labels` / concurrency identity still attach through the registered ActiveJob extension on 7.3+.
- Fork `amkisko/sentry-ruby` `main` merged upstream through 7.3.0 and pushed to GitHub/GitLab; tag `7.3.0` pushed there.
