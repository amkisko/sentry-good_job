# sentry-good_job 7.2.0

## Participants

- Andrei Makarov

## Decisions

Cut 7.2.0 on 2026-11-19 to absorb published `sentry-ruby` / `sentry-rails` 7.3.0 without deprecating this gem. Keep cron monitors, IGNORE defaults, and Good Job context on both 7.2 and 7.3 reporter APIs.

## Effects

- Setup skips `SentryReporter.sentry_context` alias when the method is absent (7.3 job-extension path).
- `RailsActiveJobExtension` prepends Good Job context onto `Sentry::Rails::ActiveJobExtension` on 7.3+.
- Appraisal pins move to `sentry-ruby` / `sentry-rails` `~> 7.3.0`; gemspec stays `sentry-ruby >= 7.0, < 8.0`.
- Version `7.2.0`.

## Next

Commit on main, then `make release` (tag, gem push, GitHub release).
