# sentry-good_job 7.1.0

## Participants

Andrei Makarov (@amkisko)

## Decisions

Cut 7.1.0 on 2026-11-06 for Good Job v5 readiness: labels in Sentry context, legacy concurrency key when present, concurrency/throttle exceeded errors in `IGNORE_DEFAULT`, gemspec ceiling `< 6.0`.

## Effects

- `ContextHelpers.add_context` sends `labels` from `good_job_labels` and optional `concurrency_key`.
- Manual `add_tags` may include `concurrency_key`; labels stay in context (cardinality).
- `IGNORE_DEFAULT` adds `ConcurrencyExceededError` and `ThrottleExceededError`.
- Dependency: `good_job >= 3.0, < 6.0`.
